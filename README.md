# Сайт ремонтной мастерской (ПК / ноутбуки / периферия)

## Как открыть
- Откройте файл `index.html` двойным кликом (или перетащите в браузер).

## Страницы
Сайт‑визитка на одной странице: `index.html` (разделы по якорям — `#services`, `#prices`, `#about`, `#contacts`, `#request`).

Старые адреса (`services.html`, `prices.html` и т.д.) перенаправляют на нужный раздел главной.

## Что поменять под себя
### Контакты (телефон/почта)
Файл: `assets/js/main.js`
- `CONTACTS.phone` и `CONTACTS.phonePretty`
- `CONTACTS.email`

### Адрес и график
Файл: `index.html`, раздел **Контакты** (`#contacts`).

### Цены и тексты
Файл: `index.html` — разделы **Услуги**, **Цены**, **О мастерской**, **Отзывы**, **FAQ**.

## Структура
- `index.html` — вся разметка
- `assets/css/styles.css` — стили и адаптив
- `assets/js/main.js` — меню, FAQ, год в футере, отправка заявки (почта/буфер)
